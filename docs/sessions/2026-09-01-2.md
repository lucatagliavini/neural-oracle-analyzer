### Decisioni tecniche acquisite (registrate nel piano)

| Problema | Soluzione adottata |
|---|---|
| ksh non ha `source` | Usare `.` (dot) per eseguire env file |
| Espansione `$` nelle query | `printf 'format' "$query"` locale, pipe a SSH — no here-doc con variabili |
| ORACLE_VERSION in subshell non propagata | Versione emessa come riga 1 stdout; caller usa `_extract_version` |
| `PROMPT marker` concatena il comando successivo | Riga blank obbligatoria dopo `PROMPT ORAMARKER` |
| Riga vuota iniziale nell'output sqlplus | `grep -v '^[[:space:]]*$'` prima del parser awk |
| Marker con trattini (`---DATA---`) troncato da sqlplus | Usare marker senza caratteri speciali: `ORAMARKER` |
