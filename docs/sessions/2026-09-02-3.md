### Refactor lib/oracle_conn.sh — 3 nuove funzioni

Prima di procedere con M4, la libreria è stata estesa per eliminare la duplicazione di codice tra i tool esistenti e preparare il terreno per `check_fra_usage.sh` (tool multi-query).

#### Nuove funzioni aggiunte

**`validate_args TOOL ENV HOST INST`**
- Centralizza la validazione di ENVIRONMENT + HOSTNAME + INSTANCE_NAME
- In caso di errore: stampa direttamente l'envelope JSON su stdout e restituisce 2
- Uso: `validate_args "$TOOL" "$ENV" "$HOST" "$INST" || exit $?`
- Elimina ~15 righe di boilerplate da ogni tool che non usa `run_tool`

**`classify_error STDERR_TEXT`**
- Analizza il testo stderr di `run_sqlplus_raw` e stampa il codice errore appropriato
- Codici possibili: `connection_failed` | `missing_env_file` | `query_failed`
- Elimina l'if/elif duplicato presente in `run_tool` e `list_pdbs.sh`

**`run_sqlplus_raw HOST INST SQL_BLOCK`**
- Trasporto SSH puro: esegue un blocco SQL arbitrario senza imporre struttura
- Il chiamante controlla l'intero SQL_BLOCK (marker, WHENEVER, HEADING, EXIT)
- stdout = output grezzo sqlplus; stderr = diagnostica prefissata con codice errore
- Permette tool multi-query (es. `check_fra_usage.sh`) senza duplicare la logica SSH

#### Refactor conseguente

- **`run_sqlplus_query`** delegato a `run_sqlplus_raw` — logica SSH rimossa, ora è solo un wrapper che aggiunge la struttura fissa (versione → ORAMARKER → query)

- **`list_pdbs.sh`**: 20 righe di validazione → 1 riga (`validate_args ... || exit $?`); classificazione errori → `classify_error`
- **`scan_alert_log.sh`** e **`tail_alert_log.sh`**: stessa riduzione della validazione
- Sostituiti tutti gli `echo "$var"` con `printf '%s\n' "$var"` per coerenza
