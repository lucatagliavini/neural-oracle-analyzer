### Bug 1 — `list_instances_on_host` restituiva `data: []` su PROD

**Root cause**: il glob `ls ~/NP*.env` nella riga 46 era hardcoded per il naming noprod.
Su PROD le istanze hanno nomi diversi (`BPMSPROD`, `PEGAPROD`, `LPDPROD`, `IDMPROD`, `RLXREPOP`, `IDM`) che
non matchano `NP*`. Il tool restituiva array vuoto senza segnalare errore (bug silenzioso).

**Secondo problema scoperto**: il quoting `'"'"'*.env'"'"'` per passare il glob via SSH inibisce
l'espansione su ksh AIX — le virgolette singole attorno a `*.env` bloccano il globbing
sia in bash che in ksh. Il glob non veniva mai espanso → no file trovati → `data: []`.

**Terzo problema**: `grep -s` non è supportato su AIX ksh → rimosso (sostituito con `2>/dev/null`).

**Fix applicato** in `tools/list_instances_on_host.sh`:
- `ls ~/NP*.env` → `ls $HOME/*.env 2>/dev/null` (nessuna quote attorno al glob)
- Loop `for f in $(ls $HOME/*.env 2>/dev/null)` — ksh espande il glob
- Filtro CDB: `grep "^ORACLE_PDB_SID=" "$f" 2>/dev/null` — CDB hanno ORACLE_PDB_SID vuoto/assente
- `grep -s` → `grep ... 2>/dev/null`

**Risultato**: `axproradb01 PROD` → 6 istanze CDB trovate correttamente:
BPMSPROD, IDM, IDMPROD, LPDPROD, PEGAPROD, RLXREPOP.

### Bug 2 — `identify_instance` produceva JSON malformato su Oracle 12.1

**Root cause**: `SET MARKUP CSV ON` è stato introdotto in Oracle 12.2. Su Oracle 12.1,
sqlplus ignora il comando e produce output tabulare con tab come separatore di colonne —
non CSV con virgole. Il CSV parser `_csv_to_json_array` aspettava header CSV su NR==1,
ma con `SET PAGESIZE 0` + formato tabulare riceveva dati raw senza header.

Output grezzo su Oracle 12.1 (errato):
```
{"bpmsprod":axproradb01}
{"bpmsprod":12.1.0.2.0\t  OPEN\t...}
```

**Fix applicato** in `lib/oracle_conn.sh`:

1. `SET MARKUP CSV ON` → `SET COLSEP ","` (compatibile 11g, 12.1, 12.2, 19c)
2. `SET PAGESIZE 0` → mantenuto per la query versione, aggiunto `SET PAGESIZE 9999` prima
   della query dati (dopo ORAMARKER) — necessario per emettere la riga header su Oracle 12.1
3. `SET LINESIZE 32767` aggiunto — evita il wrap delle righe su valori lunghi
4. `_csv_to_json_array` aggiornato:
   - Aggiunto `trim()` su chiavi e valori (rimuove padding spazi/tab di Oracle)
   - `unquote()` applicato prima di `trim()` — gestisce sia valori quotati (19c) che non (12.1)
   - Logica valore: stringa vuota → null, numerico puro → numero, resto → stringa JSON
   - Riga separatori `---` ora ignorata: `/^[-,[:space:]]+$/ { next }`

**Stessa fix** propagata a `tools/pga_sga_by_pdb.sh`, `tools/pga_by_pdb_session.sh`,
`tools/check_fra_usage.sh` (usano `run_sqlplus_raw` con sql_block proprio).

`tools/list_pdbs.sh` lasciato con `SET MARKUP CSV ON`: usa `show pdbs` che produce CSV
solo con MARKUP ON, e il tool ritorna `unsupported_version` su Oracle < 12c comunque.

**Risultato**: `identify_instance PROD axproradb01 BPMSPROD` → JSON valido con tutti i campi:
```json
{"instance_name":"BPMSPROD","host_name":"axproradb01","version":"12.1.0.2.0",
 "status":"OPEN","database_status":"ACTIVE","instance_role":"PRIMARY_INSTANCE",
 "startup_time":"2025-05-14 22:26:53"}
```

## Gotcha aggiunti

22. **`SET MARKUP CSV ON` non disponibile su Oracle < 12.2**: su Oracle 12.1 e 11g,
    sqlplus ignora il comando e produce output tabulare con tab. Usare `SET COLSEP ","` +
    `SET PAGESIZE 9999` (per l'header) + `SET LINESIZE 32767` per compatibilità universale.
23. **Glob ksh AIX via SSH**: quote singole attorno a `*.env` (come `'*.env'` o `'"'"'*.env'"'"'`)
    inibiscono l'espansione del glob su ksh AIX. Usare `ls $HOME/*.env 2>/dev/null` senza virgolette.
24. **`grep -s` non disponibile su AIX ksh**: usare `grep ... 2>/dev/null` come equivalente.
25. **Riga separatori `---` nell'output sqlplus**: con `SET COLSEP ","` Oracle emette una riga
    di soli trattini tra header e dati. Il parser `_csv_to_json_array` la deve ignorare
    (`/^[-,[:space:]]+$/ { next }`).
