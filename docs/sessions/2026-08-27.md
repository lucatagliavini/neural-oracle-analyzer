3. **Nuovi vincoli di progetto raccolti dall'utente**:
   - Stack: bash, awk, python3.
   - Host server MCP: RHEL 9.8 Linux on Power (`ppc64le`), macchina `lxprworkerlana01`.
   - Target da diagnosticare: anche server **AIX**, oltre a Linux.
   - MCP esposto via **HTTP** con **API key fissa** in configurazione client.
   - Accesso permanente: SSH chiavi scambiate, `root@lxprworkerlana01.servizi.gr-u.it`.
   - Una volta esistente codice funzionante → creare `deploy.sh` per il deploy su quella macchina.
   - Una volta testabile, il servizio sarà raggiungibile sia via HTTP (da Claude Code) sia via SSH diretto per debug.
   - → Salvato in `docs/specs/infrastruttura.md` (nuovo file) e in `docs/specs/architettura.md` (sezioni "Piattaforme target e vincoli di compatibilità" ed "Esposizione del server MCP").

4. **Consigli di design forniti** (in fase di revisione, non ancora tutti confermati):
   - Portabilità awk/bash/python3 tra RHEL ppc64le e AIX (rischio: gawk ha estensioni non POSIX che sembrano "standard" ma non girano sull'awk nativo AIX).
   - Sicurezza esposizione MCP via HTTP + API key fissa: non committare la key, valutare restrizione per IP come già previsto per SSH.

5. **Decisione chiave dell'utente**: i tool di log analysis (`scan_alert_log.sh`, `tail_alert_log.sh`) leggeranno l'alert log da un **mount NFS locale sull'host MCP**, non via SSH+awk remoto sul target AIX. Se il mount non è presente/raggiungibile, il tool deve restituire un errore JSON esplicito (es. `{"error": "log_not_found", ...}`), **senza fallback automatico via SSH**.
   - Implicazione notata e registrata: con questa scelta, l'unica cosa che esegue effettivamente su un target AIX in tutto l'elenco tool pianificato è `sqlplus` stesso (invocato via SSH) — un binario Oracle, non codice nostro. Il vincolo di compatibilità POSIX awk/bash/python3 su AIX è stato quindi declassato in `docs/specs/architettura.md` da "blocco attivo" a "principio di riserva", non vincolante per i tool attualmente pianificati.
   - Aggiornato l'elenco "Punti aperti da validare" in `CLAUDE.md`: rimosso il punto sul mount NFS (risolto), rinumerati i restanti, aggiunta nota non bloccante sui vincoli AIX.
