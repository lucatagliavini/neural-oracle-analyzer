## Cosa è stato fatto

### Review e refactor di lib/oracle_conn.sh (post-M1)

Tre problemi corretti prima di procedere con M2:

1. **Connessioni SSH ridondanti eliminate**: `run_sqlplus_query` usava 3 connessioni SSH (verifica reach + verifica env file + query). Ora ne usa 1 sola. Gli errori SSH/env file vengono rilevati dall'output stderr classificato con prefissi (`connection_failed:`, `missing_env_file:`, `query_failed:`).

2. **`build_error_json` con versione opzionale**: aggiunto parametro `VERSION` opzionale (default null). Necessario per `unsupported_version` dove la versione è nota.

3. **`_extract_version`/`_extract_data` robuste**: accettano sia argomento che stdin. Documentato che `printf '%s\n'` garantisce il newline.

4. **Aggiunta `run_tool`**: funzione che incapsula l'intero flusso (validazione → query → envelope) per i tool semplici. Riduce ogni tool a ~3 righe.

Aggiunta nota in `oracle_conn.sh`: i tool **non devono usare `set -e`** — `run_tool` restituisce exit code significativo (0/1/2) che `set -e` intercetterebbe come errore fatale.

### M2 — 4 tool di discovery implementati e validati

#### Tool prodotti
| Tool | Funzione | Pattern |
|---|---|---|
| `list_instances_on_host.sh ENV HOST` | SSH + `ls ~/NP*.env` → lista CDB | no sqlplus |
| `identify_instance.sh ENV HOST INST` | `v$instance` → info istanza | `run_tool` |
| `list_pdbs.sh ENV HOST INST` | `show pdbs` → lista PDB | blocco SQL manuale (show pdbs ≠ SQL) |
| `get_diag_home.sh ENV HOST INST` | `v$parameter diagnostic_dest` | `run_tool` |

#### Scoperte tecniche in M2

- **`show pdbs` è un comando sqlplus**, non SQL — non supporta `WHENEVER SQLERROR EXIT 1`. Gestito con blocco SQL custom identico a `run_sqlplus_query` ma senza WHENEVER.
- **Colonne con spazio** (es. `OPEN MODE` → `open_mode`): normalizzazione aggiunta nel parser `_csv_to_json_array` con `gsub(/ /, "_", key)`.
- **`set -e` incompatibile con `run_tool`**: se il tool usa `set -e` e `run_tool` restituisce exit 2 (errore validazione), bash termina lo script senza emettere il JSON. Regola fissata: `set -uo pipefail` + `exit $?` esplicito.
