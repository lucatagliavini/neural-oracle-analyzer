### Sub-Task 2 — `tools/os_cpu_stats.sh`

Tool primitivo CPU. Firma: `ENV HOSTNAME [--samples=N] [--interval=S]`.

- OS: AIX e Linux — `vmstat 1 1` / `vmstat -n 1 1`
- CPU count: `bindprocessor -q | tr | grep -c` (AIX) o `nproc` (Linux)
- Parse: awk POSIX; rileva header vmstat su riga `/us/ && /sy/`
- Output: `{os_type, cpu_count, samples[], summary{cpu_user_pct, cpu_sys_pct, cpu_idle_pct, cpu_wait_pct, run_queue}}`
- Statistiche: min/max/avg/p95/p99 con bubble sort + interpolazione lineare percentili

**Gotcha**: `sprintf(multiriga)` nell'awk inline causa "unexpected newline" su alcune versioni gawk. Fix: usare concatenazione di stringhe diretta (`entry = "..." x "..."`) invece di `sprintf(...)` con la stringa spezzata su più righe.

### Sub-Task 3 — `tools/os_memory_stats.sh`

Tool primitivo memoria. Firma: `ENV HOSTNAME [--samples=N] [--interval=S]`.

- AIX: `svmon -G` (senza `-O unit=byte` — non disponibile su 12.1) + `lsps -s` + `vmstat`
- Linux: `free -b` + `vmstat -n`
- svmon output in **pagine** (tipicamente 4KB); conversione `pagine × 4096 = bytes`
- Rileva page size dalla riga `s 4 KB` nell'output di svmon; default 4KB se assente
- Separatore sezioni nel single SSH call: `__LSPS__` e `__VMSTAT__`
- Output: `{os_type, samples[], summary{ram_used_bytes, swap_used_bytes, page_in_per_sec, page_out_per_sec}}`

**Gotcha AIX**: `svmon -G -O unit=byte` non disponibile su Oracle 12.1 AIX — usare `svmon -G` e moltiplicare le pagine per 4096.

### Sub-Task 4 — `tools/os_disk_stats.sh`

Tool primitivo disco. Firma: `ENV HOSTNAME [--samples=N] [--interval=S] [--fs=PATH]`.

- `df -k` sempre (POSIX entrambi gli OS); parsing differenziato:
  - Linux: `$5=Use% $6=Mount` (heuristica: `$5 ~ /%/`)
  - AIX: `$2=1024-blocks(KB) $3=Free(KB) $4=%Used $NF=Mount`
- `iostat` opzionale: `-d 1 1` (AIX) / `-xd 1 1` (Linux); se mancante → `io_available: false`, no errore
- Output: `{os_type, filesystems[], io_samples[], io_available, summary{io:{<device>:{reads,writes,kbps,await}}}}`

**Gotcha AIX df**: `print "["` aggiunge `\n` che invalida il JSON finale. Usare `printf "["` e `printf "]"` nell'awk.

### Sub-Task 6 — `mcp/orchestration.py` — `diagnose_os_pressure`

Orchestrato che esegue in parallelo:
- `os_cpu_stats`, `os_memory_stats`, `os_disk_stats` (primitivi OS)
- `check_memory_pressure` (orchestrato Oracle)
- `check_resource_limits`, `sessions_by_user` (primitivi Oracle)

**Logica correlazione** (regole euristiche):
- run_queue > 2×cpu_count → rosso; > cpu_count → giallo
- cpu_wait > 40% → rosso; > 20% → giallo
- swap_used > 80% → rosso; > 50% → giallo
- ram_free < 5% → rosso; < 10% → giallo
- page_out > 10/s → rosso; > 1/s → giallo
- disk_await_p95 > 100ms → rosso; > 50ms → giallo
- ≥2 indicatori rossi → `alta`; 1 rosso o ≥2 gialli → `media`; else → `bassa`

**Output summary**: `{livello_pressione_os, livello_pressione_oracle, os_type, indicatori_critici_os, indicatori_attenzione_os, correlazioni, raccomandazioni, metriche_os, pressione_oracle_detail}`

## Gotcha aggiunti

26. **`sprintf(multiriga)` awk inline**: alcune versioni di gawk/mawk interpretano la chiamata `sprintf(fmt, ...)` con la stringa di formato spezzata su più righe fisiche come "unexpected newline or end of string". Usare concatenazione diretta: `entry = "pre" x "mid" y "post"` invece di `sprintf("pre%smid%spost", x, y)`.
27. **`print` vs `printf` in awk inline**: `print "["` aggiunge `\n` — se il JSON viene poi concatenato con altri pezzi nella stessa shell variable, il newline invalida il parsing. Usare sempre `printf "["` e `printf "]"` per output JSON in awk tool.
28. **`svmon -G -O unit=byte` non disponibile su AIX < 7.2**: usare `svmon -G` (output in pagine) e moltiplicare per la page size (rilevata dalla riga `s N KB` dell'output; default 4KB).
29. **`df -k` AIX**: colonne diverse da Linux — `$2=1024-blocks(KB) $3=Free(KB) $4=%Used $NF=MountPoint`. Heuristica di rilevamento: se `$5 ~ /%/` → Linux, altrimenti AIX.
